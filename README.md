# AI Roleplay Best Practices - Notes From Building

Great roleplay is a collaboration, not a monologue.

Give the character room to act, not just react. Describe intent, leave hooks, and let the scene breathe instead of steering every beat.

The best sessions feel co-written, and that only happens when the character has persistent context to build on.

Set the stage, then trust the character to move.
